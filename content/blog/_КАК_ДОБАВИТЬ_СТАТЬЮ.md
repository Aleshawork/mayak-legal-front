# Как добавить статью в блог

Одна статья — один файл `.md` в этой папке. Файлы, имя которых начинается с `_`, сборка пропускает.

В начале файла блок между двумя строками `---`:

```
---
title: Заголовок статьи
description: Описание для поиска, до 160 знаков
slug: adres-stati
date: 2026-10-20
category: Проверка квартиры
excerpt: Одна строка для карточки в списке статей
read: 3 мин
---
```

- `slug` — адрес страницы `mayak-legal.ru/blog/adres-stati/`, латиница, цифры и дефис.
- `date` — день публикации. Статья выходит в 09:00 по Москве этого дня при ежедневной сборке.
- `category` — одна из рубрик: Проверка квартиры, Деньги и договор, Стройка и участок, Чек-листы.
- `excerpt` и `read` можно не писать: тогда в карточке будет описание, а время чтения посчитается само.
- `updated` — дата новой редакции, если статью переписали после выхода.

Ниже блока текст статьи. Подойдёт HTML, как в файлах опубликованных статей, или простая разметка: `## Подзаголовок`, пустая строка между абзацами, `- пункт списка`, `**жирный**`, `[текст ссылки](https://…)`.

Дисклеймер с датой и ссылки «Все статьи» и «Чек-листы» сборка добавляет сама.

Чтобы заменить опубликованную статью новой редакцией, загрузите файл с тем же `slug`. До даты из нового файла на сайте остаётся прежний текст.

Если в файле ошибка, сборка пропустит только эту статью и напишет причину в журнале запуска. Сайт при этом соберётся.
